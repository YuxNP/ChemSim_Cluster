# ChemSim_Cluster
This is the showcase for chemical similarity studies.

1.Type 2: The chemical similarity study is used in analogue studies based on MS2 features.

2.Type 1:The chemical similarity study is used in chemical ecology studies for chemotaxonomy, sample clustering, and unique feature identification based on MS1 features.
